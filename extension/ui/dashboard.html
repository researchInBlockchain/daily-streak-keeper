Setup guide

Four short steps. Changes save automatically.

  1. Log in to LeetCode in this browser

    The extension uses the login you already have in this browser. It never asks for or stores your password.

    Open leetcode.com

  2. Pick your language

    Solutions are submitted in this language.

  3. Choose how it submits

  4. Optional: add a free AI backup

    Most days a known, community-written solution exists. On days it doesn't (brand-new problems), a free AI can write one. It is tested on the examples first and fixed with the error output if it fails.

  5. Try it

    Run it once now to check everything works. After that it runs by itself.

How it works

  1. WhenEvery 20 minutes while Chrome is open, at browser start-up, when the laptop wakes up or comes back online. Once today's problem is solved, every later check stops immediately.
  2. FetchReads today's daily problem from LeetCode.
  3. FindLooks for a known solution in the open-source doocs/leetcode collection. If none works and the AI backup is on, the AI writes one.
  4. CheckRuns it on the problem's example tests, like pressing Run.
  5. SubmitSubmits it, like pressing Submit, at most 3 times a day. In "Ask me first" mode it waits for your click.
  6. Tell youShows a notification and records the result here.

LeetCode only accepts requests from its own pages, so while working the extension briefly opens a leetcode.com tab in the background and closes it when done.

    Privacy & fair use

    • Everything is stored only in this browser. There is no server; nothing is sent to the developer.
    • Network access: leetcode.com (your own account), cdn.jsdelivr.net (public solutions), and, only if you turn it on, the AI provider you choose, with your own key.
    • Solutions from doocs/leetcode are written by its community (CC BY-SA 4.0). This tool keeps your streak; it does not do your learning for you. "Ask me first" mode is a good way to read each day's solution.
    • Not affiliated with or endorsed by LeetCode. Automated submissions may conflict with LeetCode's terms of service. You use it on your own account at your own risk.
